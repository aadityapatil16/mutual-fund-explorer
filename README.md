# Mutual Fund Explorer

A FinTech dashboard built with HTML, CSS, and JavaScript that integrates MFAPI to fetch live Indian mutual fund data, display NAV details, and visualize historical performance trends using Chart.js.

## Features

- Search Indian mutual funds
- Fetch live NAV data using MFAPI
- Display AMC, category, scheme code and NAV date
- Visualize historical NAV performance using interactive charts
- Responsive glassmorphism UI

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- MFAPI
