# Mutual Fund Explorer

A FinTech dashboard to explore Indian mutual funds, view live NAV data, and analyze historical performance trends.

## Features

- Search Indian mutual funds
- Fetch live NAV data using MFAPI
- Display AMC, category, scheme code and NAV date
- Visualize historical NAV performance using interactive charts
- Responsive glassmorphism UI

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- MFAPI

## Project Preview

A frontend FinTech application that helps users explore mutual fund information through API-based data visualization.
